-🎯 Guess the Number Game:

An interactive number guessing game built using HTML, CSS, and JavaScript.

## About the Project

The computer randomly selects a number between 1 and 100. Your goal is to guess the correct number using the hints provided.

## Features

- Random number generation
- Hints for guesses that are too high or too low
- Attempt counter
- Play Again button to start a new game
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter a number between 1 and 100.
4. Click **Check My Guess**.
5. Use the hints to find the correct number.
